# LGTV Pro Display

This module controls LG's Pro Displays.

## Configuration

- IP/Port of Display (default of TCP port 9761)
- Set ID (0 - 99)
- Polling Rate
- Enable Verbose Logging

## Actions

- Power On/Off
- Set Input Source
- Display Mute On/Off

## Feedbacks

- Power State
- Input Source is [x]
- Display is Muted

## Variables

- Power State
- Input Source
- Display Mute State
